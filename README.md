# DevHub
A modern all-in-one productivity dashboard designed for developers to track and manage progress featured with Local Storage.

# Features
- Quick statistics dashboard.
- GitHub Profile Finder through User id.
- Notes section.
- Pomodoro Timer to increase productivity.
- Daily goals section.

# Tech Stack 
- Frontend
HTML, CSS, JAVASCRIPT
- APIs
GitHub REST API
- Storage
LocalStorage

# Learning Objectives
- DOM Manipulation
- API Integration
- Asynchronous Javascript
- LocalStorage
- UI/UX Development
